# FastScan Dashboard

Локальная панель склада Испании для FastScan. Показывает заказы, вес, коробки,
партии и количество поисков клиентов. Onza API обновляется каждые 30 секунд,
история сохраняется в SQLite, а браузер получает изменения без перезагрузки.

## Источники данных

- **Onza API:** коробки и партии.
- **Firestore:** зарегистрированные заказы, вес и суточный счётчик поиска клиентов.
- **SQLite:** локальная история и последний успешный снимок.

Имена клиентов и поисковые строки в статистику не записываются.

## Первый запуск

1. Установите Docker Desktop.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `ONZA_LOGIN` и `ONZA_PASSWORD`.
4. Создайте папку `secrets` и положите туда Firebase service account под именем
   `firebase-service-account.json`. Этот файл исключён из Git.
5. Запустите:

```powershell
docker compose up -d --build
```

Откройте <http://127.0.0.1:8080>.

Проверить состояние контейнера:

```powershell
docker compose ps
docker compose logs -f dashboard
```

## Демонстрационный режим

Чтобы посмотреть интерфейс без Onza и Firebase, установите в `.env`:

```text
DASHBOARD_DEMO=true
```

и перезапустите контейнер.

## Окно поверх остальных окон

Компактное окно Windows находится в `desktop-widget`. После запуска контейнера:

```powershell
cd desktop-widget
.\build-widget.ps1
.\dist\FastScanDashboardWidget.exe
```

Окно открывает страницу `/widget`, остаётся поверх других окон и не содержит
логинов или ключей. Двойной щелчок открывает полную панель в браузере.

## Безопасность

- `.env` и `secrets/` не коммитятся.
- Onza-токен хранится только в памяти контейнера и обновляется после `401`.
- Порт по умолчанию привязан к `127.0.0.1` и недоступен другим компьютерам сети.
- Firebase service account используется только серверной частью контейнера.

## API панели

- `GET /api/dashboard` — полный текущий снимок;
- `GET /api/history?days=31` — история;
- `GET /api/parties` — партии;
- `GET /api/parties/{guid}/boxes` — коробки партии;
- `POST /api/refresh` — внеочередное обновление;
- `GET /events` — поток обновлений SSE.
